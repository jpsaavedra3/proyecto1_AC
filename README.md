# Proyecto 1 — Calculadora de 4 bits en FPGA

ICC3302 Arquitectura de Computadores — Universidad de los Andes, 2026-2

Calculadora de 4 bits descrita en Verilog a nivel de compuertas, implementada
en una FPGA Lattice iCE40 HX1K (Nandland Go Board).

## Integrantes
- Felix Svensson
- Juan Pablo Saavedra
- Martin Heiremans

## Estructura
- `src/` — módulos Verilog del diseño
- `tb/` — testbenches
- `constraints/` — asignación de pines de la Go Board (.pcf)
- `docs/` — informe, mapas de Karnaugh y capturas de GTKWave
- `build/` — archivos generados (no versionado)
